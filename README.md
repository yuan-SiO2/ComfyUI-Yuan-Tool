# ComfyUI-Yuan-Tool

ComfyUI 自定义节点集：面向 MiniMax H3 视频生成的**时间轴工作流**工具，包含图像处理、文本处理、CLIP 时间轴与引导注入等节点。

## 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/yuan-SiO2/ComfyUI-Yuan-Tool.git
```

依赖（`requirements.txt`）：`opencv-python`、`numpy`、`torch`、`Pillow`、`color-matcher`、`nvidia-vfx`

## 节点清单

### 图像（Yuan Tool/图像）

| 节点 | 说明 |
|---|---|
| **多帧参考** | 将主体图/背景图扩展为带时间感知注意力的参考帧序列。输入：主体图、背景图、主体数量、主体帧数、起始帧、参考强度、参考阈值。输出：参考帧、参考掩码。无有效输入时兜底输出 1 张 64×64 空图（全黑）；主体数量为 0/None 时整体背景作为单张参考 |
| **筛选图像** | 从图像列表中按 帧数+起始帧 筛选，越界自动裁切；无有效输入时输出 1 张 64×64 空图 |
| **加载批量图像** | 多滑轨批量图像加载器（复刻自 WhatDreamsCost-ComfyUI Multi Image Loader）。最多 20 轨，每轨可批量上传图像并独立输出（批量图像A~T）；使用中心裁切防止失真；尺寸按 16 的倍数 lanczos 向上取整对齐 |
| **色彩匹配** | 参考图 → 待匹配图进行颜色迁移，可选掩码控制匹配区域，多模式 |
| **全景预览** | 预览视频潜空间（640×360），支持多种预览模式并可放大保存 |
| **全景接缝** | 对视频潜空间做时域接缝修补（掩码插值），消除全景拼接痕迹 |

### 画布（Yuan Tool/画布）

| 节点 | 说明 |
|---|---|
| **Yuan_画布** | 基于 Fabric.js 的合成画布编辑器：背景 + 多图层/文字，可交互拖拽编辑，导出合成图（自动 16 倍数对齐） |

### 文本（Yuan Tool/文本）

| 节点 | 说明 |
|---|---|
| **文本处理** | 分割段落/时间标记，可选输出任一段落。选取段落 = -1 时输出全部段落；留空时总段输出为空字符串 |
| **列表编号** | 为段落逐行添加编号（支持编号后缀，后缀与内容间无硬编码空格）。空输入返回 `[""]`，保证列表输出不断裂 |
| **格式转换** | 任意输入（字符串/列表/元组/None 等）统一转为字符串列表；空容器返回 `[""]` |
| **长度** | 统计文本长度与行数，支持多行合并为整体 |
| **出场排序** | 按验证对象在文本中的**首次出现位置**升序排序输出（去重、未出现跳过） |
| **文本批量替换** | 支持正则/通配符，多组查找替换。采用**最长匹配优先**避免子串误替换；开启**台词保护**后引号内（`"` `'` `“”` `‘’` `「」` `『』`）的说话内容不参与替换 |
| **分镜角色替换** | 接入 JSON提取 的「角色道具场景」与「分镜序列」输出：解析每行 `<Picture N>：名称，描述…` 定义，将名称（第一个逗号前）在分镜序列文本中**全部替换为对应 `<Picture N>` 标记**（最长匹配优先）；**台词归属特殊规则**（受「参考音频」开关控制）：开启时 `名称+引导句+：+<d>台词`（如 `沈惊鸿低声说：<d>…</d>`）中名称替换为归属代号 `(SN)`（如 `(S1)低声说：<d>…</d>`），关闭时不做 `(SN)` 替换、名称走普通替换输出 `<Picture N>`，名称前须为句首/句末标点/逗号边界、引导句不含标点（防「甲对乙说」误归属）；**台词保护**开启后引号内及 `<d>...</d>` 标签内的说话内容不参与替换 |
| **JSON提取** | 从 JSON 提取剧本信息。输入：JSON、索引、档案选择、角色输出/道具输出/场景输出；输出：整体风格、档案、分镜序列、角色道具场景、角色索引、道具索引、场景索引、索引时长、场景判断。**档案端口通过「档案选择」输出对应档案**（角色/音色/道具/场景）；分镜序列端口**整合输出** `detailed_description:`(整体风格) + 时间段逐行编号 `[Shot N]` + `overall_soundscape:`(环境音) + `non_diegetic_music:`(BGM)，标签与内容间仅换行不空行、各块间空行分隔，**类型含「武戏」时时间段不加 `[Shot N]` 编号、原行输出**；**索引未匹配到分镜时仍输出该空格式（不报错）**；角色道具场景端口先在所选分镜的时间段内容中**最长匹配优先**识别角色和道具档案、再根据分镜标题智能匹配场景档案（均排除引号内台词内容），按 **角色→道具→场景** 顺序输出对应档案的完整描述，整体以 `retention_analysis:` 开头换行输出，每条描述前加 `<Picture N>` 序号（从1连续编号），并可由「角色输出/道具输出/场景输出」三个开关独立控制是否输出对应部分；角色索引/道具索引端口输出匹配到的角色/道具在对应档案中的0基序号（逗号分隔），场景索引端口输出匹配到的场景档案0基序号（未匹配为空），三者均受对应输出开关控制、关时输出空文本；**索引时长锁定所选编号分镜「类型」字段中的时长**（如 武戏：12秒→12、文戏：8s→8，单位 s 或无单位均可），类型无数字时回退时间段最大结束时间；场景判断输出布尔值，比较当前索引与后一索引分镜标题的场景关键词（如「韩家土屋卧房-深夜未眠」取「-」前部分）是否相同，最后一个编号默认输出假 |

### 选项（Yuan Tool/选项）

| 节点 | 说明 |
|---|---|
| **选项 (Primitive)** | 前端虚拟节点，复刻原生 Primitive：连接任意节点的输入（含被转换为输入的 COMBO 控件）后自动**读回该输入的类型与选项**。原生 Primitive 无后端类，本节点为前端子类，无需后端注册。COMBO 输入已删除原生的**生成后控制**（选项值下拉与 control_after_generate），改为把全部选项**展开为互斥开关按钮**——只能打开一个，打开一个时其余自动关闭，点击后立即把选中选项写回目标输入；数字/文本等非 COMBO 输入保持原生行为 |

### MiniMax（Yuan Tool/MiniMax）

| 节点 | 说明 |
|---|---|
| **MiniMax-H3 视频生成** | 调用 MiniMax H3 生成视频，支持官方九大视频生成技能（产品广告、3D 动画短片、品牌宣传、游戏片头、手绘实拍、歌词 MV 等） |
| **H3 运动上下文** | 将上一片段尾部的连续帧作为不可去噪的条件行固定下来，画面和声音直接从上一片段的潜空间切片获取，跳过解码重编码过程，实现片段无缝衔接 |
| **H3 运动裁剪** | 从已解码的 H3 片段中移除头部固定的帧，同时按相同时长裁剪画面和声音，保持声画同步；可选尾部对齐消除 H3 音频网格向上取整累积的偏差 |
| **H3 保存潜空间** | 保存采样器的 AV 潜空间到磁盘（视频+音频双流），供下一次运行的运动上下文节点加载使用 |
| **H3 加载潜空间** | 加载由「H3 保存潜空间」节点保存的 AV 潜空间，仅用于运动上下文节点的「上下文潜空间」输入 |

### CLIP（Yuan Tool/CLIP）

| 节点 | 说明 |
|---|---|
| **Yuan CLIP 时间轴 (Timeline)** | 可视化时间轴编辑器，编排提示词与运动引导。详见下方工作流说明 |
| **Yuan 引导注入 (Guide)** | 接收时间轴的引导数据/运动引导数据/IC_LORA参数，将图像/视频引导帧编码后拼接注入潜空间，并实现时间感知注意力惩罚（promptrelay） |

### 放大（Yuan Tool/放大）

| 节点 | 说明 |
|---|---|
| **RTX 视频放大 (H3)** | 合并 RTX 视频超分辨率 + AV Decode Split + H3 Concat AV Latent 一体节点。支持图像直连或 MiniMax H3 联合 AV latent 输入（自动解码放大后重新合并音频），内置结果缓存。依赖 `nvidia-vfx`（需 NVIDIA RTX 显卡） |
| **H3 放大** | 纯 3D 卷积主干在 latent 空间放大 MiniMax H3 视频（24 通道），跳过「解码→像素放大→再编码」慢速往返。自动检测设备（优先 CUDA）与模型精度（跟随权重 fp32/fp16/bf16），强制关闭注意力；联合 AV latent 仅放大视频流、音频原样保留；缩放方式按倍数/目标尺寸切换时参数跟随显隐。模型放入 `ComfyUI/models/latent_upscale_models/`，下载：[MiniMax_h3_latent_Upscaler](https://hf-mirror.com/LBH-123-AI/Minimax_h3_latent_Upscaler/tree/main) |

## 时间轴工作流

时间轴节点编排各分镜的提示词、运动引导与音频，配合引导注入节点完成 H3 视频生成：

```
文本处理 → 时间轴 → 引导注入 → H3 视频生成
            ↑ 主体图 / 运动图像 / 音频
```

### 输入

- **模型 / CLIP模型 / 音频VAE**：基础组件（均可选）
- **全局提示词**：整体风格描述，支持 `@图X=描述` 格式，@ 时弹出已上传图像选择菜单，自动匹配对应图像段
- **文本输入**：上游文本节点的段落/时间标记，自动解析进时间轴；纯文本时按时间轴长度均分
- **最大帧数**：视频总帧数；**宽度/高度/帧率**：输出视频参数
- **段落图像 / 运动图像**：图像批量输入，自动成为主轨/IC-LoRA 轨的静态段
- **音频输入**：音频批量输入，自动生成音频轨段
- **潜空间**：可接入外部视频潜空间（未连接时自动生成）

### 时间轴编辑器

- **主轨**：提示词段落，逐段设置描述/长度/颜色，拖拽调整起止
- **IC-LoRA 轨**：运动引导段，支持图像/视频上传（图像默认 16 帧、视频用原始长度，超总帧数自动截取）；每个段关联一个主体描述
- **音频轨**：音频段，支持从视频提取音频
- **锁定模式**：工具栏「锁定」按钮开启后，时间轴数据与参数全部只读（仅可预览/复制）；解锁后可自由编辑并同步全部段描述
- 支持右键/键盘（Ctrl+C/V、Delete）复制粘贴、删除段；框选与属性面板联动

### 输出

模型、正向条件、视频潜空间、音频潜空间、引导数据、运动引导数据、帧率、音频。

- 引导数据/运动引导数据/IC_LORA参数 直接接入「Yuan 引导注入」节点
- 帧率/音频可接入 H3 视频生成节点
