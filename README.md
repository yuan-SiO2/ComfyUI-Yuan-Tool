# ComfyUI-Yuan-Tool

ComfyUI 自定义节点集：面向 MiniMax H3 视频生成的**时间轴工作流**工具，包含图像处理、文本处理、音频、CLIP 时间轴与引导注入等节点。

## 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/yuan-SiO2/ComfyUI-Yuan-Tool.git
```

依赖（`requirements.txt`）：`opencv-python`、`numpy`、`torch`、`Pillow`、`color-matcher`、`nvidia-vfx`、`av`

## 节点清单

### 图像（Yuan Tool/图像）

| 节点         | 说明                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **多帧参考**   | 将主体图/背景图扩展为带时间感知注意力的参考帧序列。输入：主体图、背景图、主体数量、主体帧数、起始帧、参考强度、参考阈值。输出：参考帧、参考掩码。无有效输入时兜底输出 1 张 64×64 空图；主体数量为 0/None 时整体背景作为单张参考                 |
| **图像点处理**  | 内嵌画布帧编辑器：点标注模式左键添加正面点、右键添加负面点；框标注模式拖拽添加边界框，框选中后可拖动移动、拖动四角手柄调整大小；多帧图像底部滑块逐帧切换标注；撤销/重做/清空。输出：正面点坐标、负面点坐标（JSON 字符串）、边界框（`[x1,y1,x2,y2]`）、帧索引 |
| **筛选图像**   | 从图像列表中按 帧数+起始帧 筛选，越界自动裁切；无有效输入时输出 1 张 64×64 空图                                                                                            |
| **加载批量图像** | 多滑轨批量图像加载器（复刻自 WhatDreamsCost-ComfyUI Multi Image Loader）。最多 20 轨，每轨可批量上传图像并独立输出（批量图像A\~T）；使用中心裁切防止失真；尺寸按 16 的倍数 lanczos 向上取整对齐           |
| **色彩匹配**   | 参考图 → 待匹配图进行颜色迁移，可选掩码控制匹配区域，多模式                                                                                                           |
| **全景预览**   | 交互式预览 ERP 全景图（360°/180°），支持视频批次输入；可切换全景/裁剪模式输出当前 3D 视角画面                                                                                  |
| **全景接缝**   | 对视频潜空间做时域接缝修补（掩码插值），消除全景拼接痕迹                                                                                                              |

### 画布（Yuan Tool/画布）

| 节点           | 说明                                                          |
| ------------ | ----------------------------------------------------------- |
| **Yuan\_画布** | 基于 Fabric.js 的合成画布编辑器：背景 + 多图层/文字，可交互拖拽编辑，导出合成图（自动 16 倍数对齐） |

### 视频（Yuan Tool/视频）

| 节点          | 说明                                                                                                                                                                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **加载视频 UI** | 内置视频预览与时间轴裁剪工具。从 input 目录选择视频，支持按秒/帧裁剪起止范围、交互式裁剪框（裁剪X/Y/宽度/高度）、最长边等比缩放、强制帧率提取；「智能分段输出」模式基于镜头检测自动分段（前端「检测分段」按钮预览分段并选段输出），单个分段超过 15 秒自动均分（15~~30s 对半 2 段、30~~45s 均分 3 段、45\~60s 均分 4 段，依此类推），切割点 +1 帧避免分段首帧遗留上一分镜画面；输出图像序列、音频、帧数、分段总数 |

### 文本（Yuan Tool/文本）

| 节点         | 说明                                                                                                                                                                                                                                                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文本处理**   | 分割段落/时间标记，可选输出任一段落。选取段落 = -1 时输出全部段落；留空时总段输出为空字符串                                                                                                                                                                                                                                                                          |
| **列表编号**   | 为段落逐行添加编号（支持编号后缀，后缀与内容间无硬编码空格）。空输入返回 `[""]`，保证列表输出不断裂                                                                                                                                                                                                                                                                      |
| **格式转换**   | 任意输入（字符串/列表/元组/None 等）统一转为字符串列表；空容器返回 `[""]`                                                                                                                                                                                                                                                                               |
| **长度**     | 统计文本长度与行数，支持多行合并为整体                                                                                                                                                                                                                                                                                                        |
| **出场排序**   | 按验证对象在文本中的**首次出现位置**升序排序输出（去重、未出现跳过）                                                                                                                                                                                                                                                                                       |
| **文本批量替换** | 多组查找替换，支持正则/通配符，**最长匹配优先**避免子串误替换；**台词保护**开启后引号内（`"` `'` `“”` `‘’` `「」` `『』`）的说话内容不参与替换                                                                                                                                                                                                                                    |
| **分镜角色替换** | 接入 JSON提取 的「角色道具场景」与「分镜序列」：解析每行 `<Picture N>：名称，描述…` 定义，将名称在分镜序列中替换为对应 `<Picture N>` 标记（最长匹配优先）；「参考音频」开启时**台词归属规则**把 `说话者+引导句+：+<d>台词` 中的说话者替换为 `(SN)` 归属代号（多候选取离冒号最近者，未命中时从冒号向前追溯最近的未保护标记/名称），关闭时说话者走普通替换输出 `<Picture N>`；台词保护开启后引号内及 `<d>...</d>` 内的说话内容不参与替换                                                            |
| **JSON提取** | 从剧本 JSON 提取分镜信息。输出：整体风格、档案（按「档案选择」输出角色/音色/道具/场景档案）、分镜序列（整体风格 + 时间段逐行 `[Shot N]` 编号 + 环境音 + BGM 整合输出，类型含「武戏」时不加编号原行输出）、角色道具场景（在所选分镜时间段内识别出现的角色/道具/场景档案，按 `<Picture N>` 序号输出完整描述，角色/道具/场景三开关独立控制）、角色/道具/场景索引（0 基序号）、索引时长（锁定分镜「类型」字段中的时长）、场景判断（当前分镜与上一分镜（编号-1）标题的场景关键词是否相同，相同为真、不同为假，编号1无前参考默认输出假）。「BGM输出」开关关闭时 BGM 行输出 `N/A` |

### 音频（Yuan Tool/音频）

| 节点            | 说明                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| **Yuan 音频列表** | 从输入目录加载音频文件（前端方块滑轨选择/上传，上限 30 个，支持视频文件提取音轨），按筛选索引（从 0 起、逗号分隔，如 `0` 或 `0,2,5`）输出 AUDIO 列表；留空输出全部，无效索引忽略 |
| **Yuan 音频分流** | 接收音频列表，按索引顺序分配到多个输出端口（「输出数量」控制，默认 2、上限 30）：索引 0 → 音频1，依此类推；列表不足的端口输出空音频（1ms 静音）                        |

### 选项（Yuan Tool/选项）

| 节点                 | 说明                                                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **选项 (Primitive)** | 前端虚拟节点，复刻原生 Primitive：连接任意节点的输入（含被转换为输入的 COMBO 控件）后自动**读回该输入的类型与选项**。原生 Primitive 无后端类，本节点为前端子类，无需后端注册。COMBO 输入已删除原生的**生成后控制**（选项值下拉与 control\_after\_generate），改为把全部选项**展开为互斥开关按钮**——只能打开一个，打开一个时其余自动关闭，点击后立即把选中选项写回目标输入；数字/文本等非 COMBO 输入保持原生行为 |

### MiniMax（Yuan Tool/MiniMax）

| 节点                  | 说明                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **MiniMax-H3 视频生成** | 调用 MiniMax H3 模型生成视频+音频联合潜空间，输出正向条件与 AV 潜空间接采样器使用。三种模式：**图生视频**（首/尾帧图像作为关键帧锚点）、**参考图生视频**（多路参考图像/视频/音频，提示词用 `<Picture i>`/`<Video k>`/`<Audio j>` 引用）、**数字人**（引导图像/音频锚定到任意帧，复刻官方 Add Guide） |
| **H3 运动上下文**        | 将上一片段尾部的连续帧作为不可去噪的条件行固定下来，画面和声音直接从上一片段的潜空间切片获取，跳过解码重编码过程，实现片段无缝衔接。裁剪帧数输出为字符串「状态:长度」（如 `1:34`）供「H3 运动裁剪」解析；上下文关闭或首片段时输出 `0:17` 直通                                                            |
| **H3 运动裁剪**         | 在 H3 AV 潜空间上两段式裁切（已合并原「H3 保存潜空间」功能）：第一段按「H3 运动上下文」输出的裁剪帧数字符串从头部整段裁掉固定帧（音视频共用同一时间切点，切点吸附整 VRF 组边界防闪烁）；第二段在交付潜空间尾部再切一段（启用上下文时=裁剪长度，未启用时固定 17 帧）由「保存到本地」开关控制保存到磁盘，供下一片段衔接                      |
| **H3 加载潜空间**        | 加载由「H3 运动裁剪」保存的尾段潜空间，仅用于运动上下文节点的「上下文潜空间」输入。片段序号 0 表示首片段（不读文件，条件化直通）；支持手动上传 latent 文件优先加载                                                                                                    |

### CLIP（Yuan Tool/CLIP）

| 节点                           | 说明                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| **Yuan CLIP 时间轴 (Timeline)** | 可视化时间轴编辑器，编排提示词与运动引导。详见下方工作流说明                                                              |
| **Yuan 引导注入 (Guide)**        | 接收时间轴的引导数据/运动引导数据，将图像/视频引导帧编码后拼接注入潜空间，并实现时间感知注意力惩罚（promptrelay）；可选 IC\_LORA 参数与 MSR LoRA 适配 |

### 放大（Yuan Tool/放大）

| 节点                | 说明                                                                                                                                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **RTX 视频放大 (H3)** | 合并 RTX 视频超分辨率 + AV Decode Split + H3 Concat AV Latent 一体节点。支持图像直连或 MiniMax H3 联合 AV latent 输入（自动解码放大后重新合并音频），内置结果缓存。依赖 `nvidia-vfx`（需 NVIDIA RTX 显卡）                                                                                                                                                                      |
| **H3 放大**         | 纯 3D 卷积主干在 latent 空间放大 MiniMax H3 视频（24 通道），跳过「解码→像素放大→再编码」慢速往返。自动检测设备（优先 CUDA）与模型精度（跟随权重 fp32/fp16/bf16），强制关闭注意力；联合 AV latent 仅放大视频流、音频原样保留；缩放方式按倍数/目标尺寸切换时参数跟随显隐。模型放入 `ComfyUI/models/latent_upscale_models/`，下载：[MiniMax\_h3\_latent\_Upscaler](https://hf-mirror.com/LBH-123-AI/Minimax_h3_latent_Upscaler/tree/main) |

## 时间轴工作流

时间轴节点编排各分镜的提示词、运动引导与音频，配合引导注入节点完成 H3 视频生成：

```
文本处理 → 时间轴 → 引导注入 → H3 视频生成
            ↑ 主体图 / 运动图像 / 音频
```

### 输入

- **模型 / CLIP模型 / 音频VAE**：基础组件（均可选）

- **全局提示词**：整体风格描述，支持 `@图X=描述` 格式，@ 时弹出已上传图像选择菜单，自动匹配对应图像段

- **文本输入**：上游文本节点的段落/时间标记，自动解析进时间轴；纯文本时按时间轴长度均分

- **最大帧数**：视频总帧数；**宽度/高度/帧率**：输出视频参数

- **段落图像 / 运动图像**：图像批量输入，自动成为主轨/IC-LoRA 轨的静态段

- **音频输入**：音频批量输入，自动生成音频轨段

- **潜空间**：可接入外部视频潜空间（未连接时自动生成）

### 时间轴编辑器

- **主轨**：提示词段落，逐段设置描述/长度/颜色，拖拽调整起止

- **IC-LoRA 轨**：运动引导段，支持图像/视频上传（图像默认 16 帧、视频用原始长度，超总帧数自动截取）；每个段关联一个主体描述

- **音频轨**：音频段，支持从视频提取音频

- **锁定模式**：工具栏「锁定」按钮开启后，时间轴数据与参数全部只读（仅可预览/复制）；解锁后可自由编辑并同步全部段描述

- 支持右键/键盘（Ctrl+C/V、Delete）复制粘贴、删除段；框选与属性面板联动

### 输出

模型、正向条件、视频潜空间、音频潜空间、引导数据、运动引导数据、帧率、音频。

- 引导数据/运动引导数据 直接接入「Yuan 引导注入」节点（IC\_LORA参数由 IC-LoRA 加载器另行提供）

- 帧率/音频可接入 H3 视频生成节点
