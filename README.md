# ComfyUI-Yuan-Tool

ComfyUI 自定义节点集：面向 MiniMax H3 视频生成的**时间轴工作流**工具，包含图像处理、文本处理、CLIP 时间轴与引导注入等节点。

## 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/yuan-SiO2/ComfyUI-Yuan-Tool.git
```

依赖（`requirements.txt`）：`opencv-python`、`numpy`、`torch`、`Pillow`、`color-matcher`、`nvidia-vfx`

## 节点清单

### 图像（Yuan Tool/图像）

| 节点 | 说明 |
|---|---|
| **多帧参考** | 将主体图/背景图扩展为带时间感知注意力的参考帧序列。输入：主体图、背景图、主体数量、主体帧数、起始帧、参考强度、参考阈值。输出：参考帧、参考掩码。无有效输入时兜底输出 1 张 64×64 空图（全黑）；主体数量为 0/None 时整体背景作为单张参考 |
| **筛选图像** | 从图像列表中按 帧数+起始帧 筛选，越界自动裁切；无有效输入时输出 1 张 64×64 空图 |
| **加载批量图像** | 多滑轨批量图像加载器（复刻自 WhatDreamsCost-ComfyUI Multi Image Loader）。最多 20 轨，每轨可批量上传图像并独立输出（批量图像A~T）；使用中心裁切防止失真；尺寸按 16 的倍数 lanczos 向上取整对齐 |
| **色彩匹配** | 参考图 → 待匹配图进行颜色迁移，可选掩码控制匹配区域，多模式 |
| **全景预览** | 预览视频潜空间（640×360），支持多种预览模式并可放大保存 |
| **全景接缝** | 对视频潜空间做时域接缝修补（掩码插值），消除全景拼接痕迹 |

### 画布（Yuan Tool/画布）

| 节点 | 说明 |
|---|---|
| **Yuan_画布** | 基于 Fabric.js 的合成画布编辑器：背景 + 多图层/文字，可交互拖拽编辑，导出合成图（自动 16 倍数对齐） |

### 文本（Yuan Tool/文本）

| 节点 | 说明 |
|---|---|
| **文本处理** | 分割段落/时间标记，可选输出任一段落。选取段落 = -1 时输出全部段落；留空时总段输出为空字符串 |
| **列表编号** | 为段落逐行添加编号（支持编号后缀，后缀与内容间无硬编码空格）。空输入返回 `[""]`，保证列表输出不断裂 |
| **格式转换** | 任意输入（字符串/列表/元组/None 等）统一转为字符串列表；空容器返回 `[""]` |
| **长度** | 统计文本长度与行数，支持多行合并为整体 |
| **出场排序** | 按验证对象在文本中的**首次出现位置**升序排序输出（去重、未出现跳过） |
| **文本批量替换** | 支持正则/通配符，多组查找替换。采用**最长匹配优先**避免子串误替换；开启**台词保护**后引号内（`"` `'` `“”` `‘’` `「」` `『』`）的说话内容不参与替换 |
| **JSON提取** | 从 JSON 提取剧本信息。输入：JSON、索引；输出：整体风格、角色档案、道具档案、场景档案、分镜序列、场景索引、角色索引、道具索引、索引时长。场景/角色/道具索引在所选分镜的时间段内容中**最长匹配优先**识别，并排除引号内台词内容 |

### MiniMax（Yuan Tool/MiniMax）

| 节点 | 说明 |
|---|---|
| **MiniMax-H3 视频生成** | 调用 MiniMax H3 生成视频，支持官方九大视频生成技能（产品广告、3D 动画短片、品牌宣传、游戏片头、手绘实拍、歌词 MV 等） |

### CLIP（Yuan Tool/CLIP）

| 节点 | 说明 |
|---|---|
| **Yuan CLIP 时间轴 (Timeline)** | 可视化时间轴编辑器，编排提示词与运动引导。详见下方工作流说明 |
| **Yuan 引导注入 (Guide)** | 接收时间轴的引导数据/运动引导数据/IC_LORA参数，将图像/视频引导帧编码后拼接注入潜空间，并实现时间感知注意力惩罚（promptrelay） |

### 放大（Yuan Tool/放大）

| 节点 | 说明 |
|---|---|
| **RTX 视频放大 (H3)** | 合并 RTX 视频超分辨率 + AV Decode Split + H3 Concat AV Latent 一体节点。支持图像直连或 MiniMax H3 联合 AV latent 输入（自动解码放大后重新合并音频），内置结果缓存。依赖 `nvidia-vfx`（需 NVIDIA RTX 显卡） |

## 时间轴工作流

时间轴节点编排各分镜的提示词、运动引导与音频，配合引导注入节点完成 H3 视频生成：

```
文本处理 → 时间轴 → 引导注入 → H3 视频生成
            ↑ 主体图 / 运动图像 / 音频
```

### 输入

- **模型 / CLIP模型 / 音频VAE**：基础组件（均可选）
- **全局提示词**：整体风格描述，支持 `@图X=描述` 格式，@ 时弹出已上传图像选择菜单，自动匹配对应图像段
- **文本输入**：上游文本节点的段落/时间标记，自动解析进时间轴；纯文本时按时间轴长度均分
- **最大帧数**：视频总帧数；**宽度/高度/帧率**：输出视频参数
- **段落图像 / 运动图像**：图像批量输入，自动成为主轨/IC-LoRA 轨的静态段
- **音频输入**：音频批量输入，自动生成音频轨段
- **潜空间**：可接入外部视频潜空间（未连接时自动生成）

### 时间轴编辑器

- **主轨**：提示词段落，逐段设置描述/长度/颜色，拖拽调整起止
- **IC-LoRA 轨**：运动引导段，支持图像/视频上传（图像默认 16 帧、视频用原始长度，超总帧数自动截取）；每个段关联一个主体描述
- **音频轨**：音频段，支持从视频提取音频
- **锁定模式**：工具栏「锁定」按钮开启后，时间轴数据与参数全部只读（仅可预览/复制）；解锁后可自由编辑并同步全部段描述
- 支持右键/键盘（Ctrl+C/V、Delete）复制粘贴、删除段；框选与属性面板联动

### 输出

模型、正向条件、视频潜空间、音频潜空间、引导数据、运动引导数据、帧率、音频。

- 引导数据/运动引导数据/IC_LORA参数 直接接入「Yuan 引导注入」节点
- 帧率/音频可接入 H3 视频生成节点
