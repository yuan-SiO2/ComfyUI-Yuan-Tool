# ComfyUI-Yuan-Tool

ComfyUI 自定义节点工具集，提供图像处理、全景预览、画布合成、色彩匹配、文本处理、格式转换以及基于时间轴的视频提示词编码等功能，适配 LTX/Wan 视频生成模型工作流。

---

## 节点列表

### 1. 多帧参考 (`YuanTool`)
- **分类**: `Yuan Tool/图像`
- **功能**: 将多张主体图像与一张背景图合成为固定帧数的参考视频，专为 LTX 2.3 Tool (Multiple-Subject-Reference) LoRA 工作流设计。

| 参数 | 类型 | 说明 |
|------|------|------|
| `1` ~ `8` | IMAGE (可选) | **单帧模式** 主体图像端口（按 1 → 2 → … → 8 顺序；`1`、`2` 常显，`3` 起递进显示：前 k 个全连接后，第 k+1 个自动出现，最多 8 个） |
| `background` | IMAGE (可选) | 背景图像，`frame_multiplier` 张，排在最后 |
| `width` | INT | 输出视频宽度 (默认 736，步长 32) |
| `height` | INT | 输出视频高度 (默认 1280，步长 32) |
| `frame_multiplier` | 选项 | 帧数倍率：8 / 16 / 24 / 32 |
| `list_mode` | BOOL | 开启后使用 `图像列表1~8` 批量端口替代 1~8 单帧端口 |
| `图像列表1` ~ `图像列表8` | IMAGE (可选) | **列表模式** 批量图像输入；`图像列表1`、`图像列表2` 常显；当 `图像列表1` 与 `图像列表2` **都连接**后自动出现 `图像列表3`，以此类推至最多 8 个（每路最多取前 8 张；**全部主体加起来最多 8 张**，超出按端口顺序截断） |

- **输出**: `output` (IMAGE) — 合成后的视频帧序列张量

#### 帧数计算公式
```
首图额外补帧 = 1（当存在至少 1 张主体 && frame_multiplier > 1 时加 1，否则为 0）
背景帧数     = frame_multiplier（当背景存在且有效）或 0（背景未接/空兜底）
总帧数       = 主体图像数量 × frame_multiplier + 首图额外补帧 + 背景帧数
```
当所有列表 + 单帧 + 背景 **全部为空（或全是空兜底图）**，输出一张 `(1, 64, 64, 3)` 的全黑空占位图（与「筛选图像」兜底一致）。

#### 空兜底识别（与「筛选图像」节点联合规则）
若任一端口接入的 IMAGE 恰好是 **形状 `(1,64,64,3)` 且全像素为 0**（即「筛选图像」在空索引时输出的兜底），**该端口视为未接入**：
- 不参与 `主体图像数量` 统计（不占用 ×frame_multiplier 帧数）
- 不会出现在最终输出的主体序列中
- 背景端口命中空兜底 → 同样不加 `frame_multiplier` 张背景帧
（任何模式：单帧 1~8、列表 1~8、background 统一遵循）

#### 图像预处理
- **主体图像**：等比例缩放，保持完整，居中放在白色画布上（不变形、不裁剪）
- **背景图像**：等比例缩放覆盖整个画布，居中裁剪（填满目标尺寸）
- **智能插值**：缩小用 INTER_AREA，放大用 INTER_LANCZOS4，无 OpenCV 时降级为 torch bicubic

### 2. 筛选图像 (`GetImage`)
- **分类**: `Yuan Tool/图像`
- **功能**: 从批量图像中按索引选取一张或多张图像。对空输入/无有效索引提供一致的空图像兜底（与「多帧参考」联合使用时自动识别为空端口）。

| 参数 | 类型 | 说明 |
|------|------|------|
| `images` | IMAGE | 输入批量图像 |
| `indexes` | STRING | 索引列表，逗号分隔，如 `"0, 1, 2"`；支持空值/空白/非法值（自动跳过） |

- **输出**: `IMAGE` — 筛选后的图像张量
- **空兜底输出**: 当 `indexes` 为空 / 全非法 / 全部越界 / 或 `images` 本身为空 batch 时，输出一张形状为 `(1, 64, 64, 3)` 的全黑零图像（下游「多帧参考」识别到该形状+全零后，**自动视为该端口未接入**，不参与帧数计算与输出）

### 3. 全景预览 (`YuanPanoramaPreview`)
- **分类**: `Yuan Tool/图像`
- **功能**: 交互式预览 ERP 全景图（360°/180°），支持视频批次输入。复刻自 ComfyUI-Panorama-Stickers，配套 WebGL 球面投影编辑器。后端将输入图像落盘为预览图，视频批次额外编码 mp4 预览；前端可输出当前 3D 视角的裁剪截图。

| 参数 | 类型 | 说明 |
|------|------|------|
| `ERP_image` | IMAGE | ERP 全景图（支持单图或视频批次 `[B,H,W,C]`） |
| `Coverage` | 选项 | 全景覆盖范围：`360` / `180` |
| `output_current_view` | BOOL | 全景模式（输出完整 ERP 图）/ 裁剪模式（输出当前 3D 裁剪截图） |
| `view_width` | INT | 裁剪模式下的输出宽度 (默认 1024) |
| `view_height` | INT | 裁剪模式下的输出高度 (默认 512) |
| `current_view_data` | STRING (隐藏) | 前端回传的当前视角截图 data URL（自动管理） |

- **输出**: `输出` (IMAGE) — 全景模式输出完整 ERP 图，裁剪模式输出当前视角截图
- **备注**: 视频预览依赖 PyAV (`pip install av`)，缺失时仅放弃 mp4 预览，不影响图像预览

### 4. 全景接缝 (`YuanPanoramaSeamPrep`)
- **分类**: `Yuan Tool/图像`
- **功能**: 为接缝修复（seam-focused inpainting）准备 ERP 图像。将接缝平移到图像中心，并生成接缝带掩码与高斯模糊掩码。

| 参数 | 类型 | 说明 |
|------|------|------|
| `image` | IMAGE | 输入 ERP 图像 `[B,H,W,C]` |
| `seam_width_px` | INT | 接缝带宽度（像素，默认 64） |
| `seam_center_offset_px` | INT | 接缝中心偏移量（正值右移，负值左移，默认 0） |
| `mask_blur_px` | INT | 掩码高斯模糊半径（默认 10，0 表示不模糊） |

- **输出**: `image` (IMAGE) — 接缝平移到中心后的图像, `mask` (MASK) — 接缝带掩码, `mask_blurred` (MASK) — 模糊后的掩码

### 5. 色彩匹配 (`YuanColorMatch`)
- **分类**: `Yuan Tool/图像`
- **功能**: 将参考图的色彩分布迁移到目标图，基于 `color-matcher` 库实现。支持批量处理与多线程加速，可用于自动色彩校正、画面调色以及光线/色温统一。复刻自 ComfyUI-KJNodes 的 ColorMatch 节点。

| 参数 | 类型 | 说明 |
|------|------|------|
| `image_ref` | IMAGE | 参考图像（提供色彩分布） |
| `image_target` | IMAGE | 目标图像（被改色的图） |
| `method` | 选项 | 匹配方法：`mkl` / `hm` / `reinhard` / `mvgd` / `hm-mvgd-hm` / `hm-mkl-hm` |
| `strength` | FLOAT (可选) | 混合强度，0 输出原图，1 完全匹配 (默认 1.0) |
| `multithread` | BOOL (可选) | 批量大于 1 时启用多线程 (默认 true) |

- **输出**: `image` (IMAGE) — 色彩匹配后的图像
- **备注**: 依赖 `pip install color-matcher`

#### 匹配方法说明
| 方法 | 说明 |
|------|------|
| `mkl` | Monge-Kantorovich 线性化 (MKL) |
| `hm` | 直方图匹配 (HM) |
| `reinhard` | Reinhard 等人的方法 |
| `mvgd` | 多元高斯分布迁移 (MVGD) |
| `hm-mvgd-hm` | HM-MVGD-HM 复合方法 |
| `hm-mkl-hm` | HM-MKL-HM 复合方法 |

### 6. Yuan_画布 (`Yuan_Canvas`)
- **分类**: `Yuan Tool/画布`
- **功能**: 自包含的画布合成器（V3），复刻自 ComfyUI-Yuan。接收最多 8 张图像作为独立图层，在内嵌的 fabric.js 编辑器中可视化放置、旋转、缩放，前端合成后的图像回传后端作为单个 IMAGE 输出。配置变化时节点会暂停执行，便于构建合成后继续。

| 参数 | 类型 | 说明 |
|------|------|------|
| `bg_image` | IMAGE | 背景图像 |
| `fabricData` | STRING | fabric.js 画布状态 JSON（前端自动管理，默认 `"{}"`） |
| `imageName` | STRING | 合成结果文件名（默认 `new.png`） |
| `width` | INT | 画布宽度 (默认 512，步长 32) |
| `height` | INT | 画布高度 (默认 512，步长 32) |
| `padding` | INT | 缓冲区大小，用于暂存不想导出的素材 (默认 100) |
| `images` | IMAGE (可选) | 作为独立图层传入的图像批次 |

- **输出**: `image` (IMAGE) — 合成后的图像

### 7. 文本处理 (`YUAN_TXTParagraphSplitter`)
- **分类**: `Yuan Tool/文本`
- **功能**: 多功能文本分割器，支持 8 种分割模式、动态输入/输出端口扩展、段落优化与选取。

#### 分割模式
| 模式 | 说明 |
|------|------|
| `端口` | 严格按 `any_x` 输入端口分割 |
| `空行` | 识别双换行符 `\n\n` 作为段落分隔 |
| `序号` | 识别 `1.` / `(1)` / `A.` 等列表标记 |
| `段落` | 每一行算一段 |
| `标题` | 智能识别章节标题（括号标题、序号标题等） |
| `数字` | 仅提取纯数字 |
| `地址` | 智能提取 Windows 文件路径（如 `D:\Data\img.png`），自动清洗格式 |
| `手动` | 识别 `|||` 分隔符进行自定义分割 |

#### 主要参数
| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | STRING | 基础文本输入 |
| `any_1` ~ `any_64` | AnyType (可选) | 动态扩展输入端口，可连接任意节点按顺序拼接 |
| `分段方式` | 选项 | 选择分割模式 |
| `段落优化` | BOOL | 去除首尾空格 / 保留原始格式 |
| `输出模式` | BOOL | 输出原始文本 / 输出分段列表 |
| `输出段落` | INT | 动态设置右侧 `段落1` ~ `段落N` 输出端口数量 |
| `输入端口` | INT | 动态设置左侧 `any_x` 输入端口数量 |
| `选取段落` | STRING | 选取指定索引的段落。`-1`（**默认**）输出所有段落；**留空** 或全空格时「总段:」为空输出（0段）；填写索引用 `0,2,4` 或 `0。1，2/3\4` 等多种分隔符 |

- **输出**: `数:` (INT) — 段落总数, `总段:` (STRING 列表) — 所有段落, `段落1` ~ `段落100` (STRING) — 单个段落
- **选取段落规则**：
  - `-1`（默认）→ 输出所有段落（原「留空=全部」语义迁移到 `-1`）
  - `""`（留空）或全空格 → 「总段:」为空列表/空文本，`段落1..N` 全部为 `""`，`数:`=0
  - `"0,2,4"` → 按 0 基索引挑选（越界索引被丢弃，负数非 `-1` 被丢弃，非法字符被跳过）

### 10. 长度 (`YUAN_TXTLength`)
- **分类**: `Yuan Tool/文本`
- **功能**: 对接入的文本长度进行计数统计，四种统计模式（列表/段落/空行/字符串），输出 `INT`。复刻自 ComfyUI-Easy-Use 的 `len any` 节点，按中文漫剧常见的四种「计数口径」扩展。

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | AnyType("*") | 要计数的文本；可接上游任意类型（list/数字/字典自动转字符串） |
| `长度模式` | 选项 | 计数方式（见下表）：`字符串`（默认）/ `段落` / `空行` / `列表` |

- **输出**: `长度` (INT) — 根据所选模式统计得到的数量

#### 长度模式说明
| 模式 | 计数规则 | 空文本输出 |
|------|------|-----------|
| `字符串` | 文本字符数（逐字符，中/英/标点/空格 各算 1） | `0` |
| `段落`   | **每一行算一个段落**（splitlines 拆分；中间空行也算一行；末尾换行不算） | `0` |
| `空行`   | 按空行分割后的「段落块数」：先 strip 首尾空白，再按连续空白行切分，非空段累计 | `0` |
| `列表`   | 上游是 list → `len(列表)`；上游不是 list → 整体视为 1（空文本为 0） | `0` |

> **与「文本处理」串联用法**：把「文本处理」切到 `输出模式 = 输出分段列表`，`总段:` 输出接到本节点，选择 `长度模式 = 列表`，即可得到段落总数（与 `数:` 输出一致）。

### 12. 文本批量替换 (`YUAN_TXTReplace`)
- **分类**: `Yuan Tool/文本`
- **功能**: 行对行的批量查找替换（第 1 行查找 → 第 1 行替换；第 2 行查找 → 第 2 行替换…）。新增 **台词保护** 开关，可让被引号包裹的「人物说话内容」完全保留原文不被替换。

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | STRING (多行) | 原始文本 |
| `查找文本` | STRING (多行) | 每行一个要查找的字符串 |
| `替换文本` | STRING (多行) | 每行一个要替换成的字符串 |
| `台词开关` (显示名 `台词保护`) | BOOLEAN | **默认关（正常替换）**。打开后，被以下引号包裹的文本不参与替换：`"..."`、`'...'`、`“...”`、`‘...’`、`「...」`、`『...』` |

- **输出**: `text` (STRING) — 替换后的文本
- **台词保护配对规则**：
  - 中文弯 / 直角引号：栈式配对，就近闭合匹配对应开 / 闭引号
  - ASCII `"` / `'`：智能判断——若当前存在同类型未闭合开引号，则优先当闭引号；否则当开引号
  - 未闭合的开引号 / 找不到对应开引号的闭引号：当作普通字符，不进入保护范围（避免误伤正文）
  - 查找字符串 **任一字符落入保护区间** → 整个匹配窗口跳过，不替换
  - 每完成一轮查找/替换后，基于最新结果重新计算保护掩码（保证前一轮引入的新引号不会错位）

### 13. MiniMax-H3 视频生成 (`Yuan_MiniMaxH3Video`)
- **分类**: `Yuan Tool/MiniMax`
- **功能**: MiniMax H3 视频生成节点（汉化版），合并复刻自 ComfyUI 原生 `MiniMaxH3ImageToVideo` 与 `MiniMaxH3ReferenceToVideo`，通过模式下拉框切换两种生成方式。支持首/尾帧关键帧锚点，或多参考图/参考视频/参考音频条件注入。
- **描述**: MiniMax-H3 视频生成：图生视频（首/尾帧关键帧）或参考图生视频（<Picture>/<Video>/<Audio> 参考）。
#### 生成模式
| 模式 | 说明 |
|------|------|
| `图生视频` | 提示词 + 可选首帧/尾帧关键帧，生成正向条件与音视频联合潜空间 |
| `参考图生视频` | 提示词 + \<Picture i\> / \<Video k\> / \<Audio j\> 参考内容，最多 9 张参考图、3 路参考视频、3 路参考音频 |

#### 公共参数（两种模式共用）
| 参数 | 类型 | 说明 |
|------|------|------|
| `模式` | 选项 | 生成模式：图生视频 / 参考图生视频 |
| `CLIP` | CLIP | 用于编码提示词的 CLIP 模型 |
| `VAE` | VAE | 用于编码关键帧/参考图像的 VAE 模型 |
| `提示词` | STRING | 视频内容的提示词描述（参考模式下可用 \<Picture i\> / \<Video k\> / \<Audio j\> 引用参考内容） |
| `宽度` | INT | 视频宽度，需为 32 的倍数 (默认 1344) |
| `高度` | INT | 视频高度，需为 32 的倍数 (默认 768) |
| `时长（帧）` | INT | 24fps 下的视频帧数，自动向上对齐到 17k+5 帧网格 (默认 124≈5秒) |

#### 图生视频模式 可选端口
| 参数 | 类型 | 说明 |
|------|------|------|
| `首帧图像` | IMAGE (可选) | 视频首帧图像，作为几何锚点 |
| `尾帧图像` | IMAGE (可选) | 视频尾帧图像 |

#### 参考图生视频模式 可选端口
| 参数 | 类型 | 说明 |
|------|------|------|
| `音频VAE` | VAE (可选) | 用于编码参考音频的音频 VAE 模型（参考模式必填） |
| `参考图尺寸` | 选项 | `匹配`：缩放到生成画面像素面积；`最大`：使用 2048px 短边获得最佳主体保真度（更慢） |
| `参考图像` | IMAGE (可选) | 参考图像列表（可连接 batch 多图，最多 9 张，超出自动切断） |
| `参考视频1` ~ `参考视频3` | IMAGE (可选) | 24fps 参考视频帧（2-15 秒），递进显示，前一路连接后下一路出现 |
| `参考视频音频1` ~ `参考视频音频3` | AUDIO (可选) | 与同编号参考视频对应的音轨，递进显示 |
| `参考音频1` ~ `参考音频3` | AUDIO (可选) | 独立参考音频，递进显示 |

- **输出**: `正向` (CONDITIONING) — 正向条件（含关键帧/参考潜空间）, `潜空间` (LATENT) — 视频+音频联合潜空间

#### 画布与帧数策略
- **画布**: 768 短边，面积上限 768×1344，逐轴取整到 32 的倍数
- **帧数**: 自动向上对齐到 `17k+5` 帧网格（训练区间约 124-362 帧，5-15 秒）
- **参考提示词标记**: 参考内容按固定顺序进入分词器，提示词中用 `<Picture i>` / `<Video k>` / `<Audio j>` 引用

---

### 14. Yuan CLIP 时间轴 (`YuanCLIPTimeline`)
- **分类**: `Yuan Tool/CLIP`
- **功能**: 可视化时间轴提示词编码节点，复刻自 ComfyUI-PromptRelay 的 Prompt Relay Encode (Timeline) 节点。为视频扩散模型 (Wan / LTX) 注入时间感知的提示词调度，自动生成视频和音频空潜空间。配套 Web 时间轴编辑器 UI。

#### 核心特性
- **时间感知注意力惩罚**: 对交叉注意力注入高斯惩罚矩阵，使不同时间段的提示词在对应帧上具有更高的注意力权重
- **自动潜空间生成**: 未连接 latent 输入时，自动生成 LTXV 兼容的视频/音频空潜空间（零张量），由采样器加噪去噪
- **text_input 智能解析**: 支持时间格式行 `"0-3s 提示词A"` 动态分配帧长，也支持纯文本行自动均分
- **提示词锁定模式**: prompt_lock 开启时，text_input 自动同步到时间轴各段落

#### 主要参数
| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | MODEL | 要补丁的扩散模型 (Wan / LTX) |
| `clip` | CLIP | 用于编码提示词的 CLIP 模型 |
| `audio_vae` | VAE | Audio VAE，用于生成音频潜空间 |
| `global_prompt` | STRING | 全局提示词，贯穿整个视频 |
| `max_frames` | INT | 像素空间总帧数 (默认 129) |
| `timeline_data` | STRING | 时间轴编辑器 JSON 状态（自动管理） |
| `local_prompts` | STRING | 各段提示词，用 `\|` 分隔（自动填充） |
| `segment_lengths` | STRING | 各段帧数，逗号分隔（自动填充） |
| `epsilon` | FLOAT | 惩罚衰减参数 (默认 1e-3，越小边界越锐利) |
| `fps` | FLOAT | 每秒帧数 (默认 24) |
| `time_units` | 选项 | 时间单位：`frames` / `seconds` |
| `width` | INT | 自动生成潜空间的目标宽度 (默认 768) |
| `height` | INT | 自动生成潜空间的目标高度 (默认 512) |
| `latent` | LATENT (可选) | 外部潜空间输入（不连接时自动生成） |
| `text_input` | STRING (可选) | 按行输入的提示词文本（支持时间格式） |
| `prompt_lock` | BOOL (可选) | 提示词锁定模式 (默认 true) |

- **输出**: `model` (MODEL) — 补丁后的模型, `positive` (CONDITIONING) — 正向条件, `video_latent` (LATENT) — 视频潜空间, `audio_latent` (LATENT) — 音频潜空间

### 2026-08-05
- **节点：多帧参考 (`YuanTool`) 功能升级**
  - 端口扩展：单帧模式由 `1~4` 扩展到 **`1~8`**；列表模式由单个 `image_list` 扩展为 **`图像列表1 ~ 图像列表8`**（每路最多取前 8 张，全部主体累计上限 8 张）
  - 递进显示（前端）：单帧 `1`/`2` 常显，`3` 起前 k 个全连接后自动出现 `k+1`；列表模式 `图像列表1`/`2` 常显，**两者都连接**后自动出现 `图像列表3`，以此类推至最多 8 路
  - 帧数公式调整：首图额外补帧仅在 `有主体 && frame_multiplier > 1` 时加 1；背景帧数由固定 8 改为 `frame_multiplier`（无背景/背景为空兜底时 = 0）
  - **空兜底识别规则**：任一端口（单帧 1~8 / 列表 1~8 / background）接入 **形状 `(1,64,64,3)` 且全像素为 0** 的张量（即「筛选图像」空索引输出的占位）→ **该端口视为未接入**：不参与帧数 ×、不产出主体/背景帧，下游不输出该端口图像
  - **全空输出兜底**：当所有主体 + 背景 **全部为空（或全是空兜底）**，输出 1 张 `(1,64,64,3)` 全黑图（即使 `width/height` 被设置为其他尺寸也一律输出 64×64）

- **节点：筛选图像 (`GetImage`) BUG 修复**
  - 修复 `indexes` 为空字符串 / 全空白 / 全非法 token（如 `abc`）/ 全部越界 / 上游 images batch 为空 时 `ValueError: invalid literal for int()` / `IndexError` 崩溃
  - 所有异常场景统一 **输出 1 张 `(1,64,64,3)` 全黑零张量**（dtype=float32，0~1 范围），保证链路不中断；并且该形状会被下游「多帧参考」**识别为空端口**，不参与帧展开

- **节点：文本处理 (`YUAN_TXTParagraphSplitter`) — 选取段落规则变更**
  - 参数 `选取段落` 默认值从 `""` 改为 **`"-1"`**
  - `-1`（新增语义）→ **输出所有段落**（等价于旧版「留空」语义）
  - `""`（留空）或全空格 → **总段输出为空**：分段列表模式下 `总段:=[]` 且 `数:=0`；合并文本模式下 `总段:=[""]`，所有 `段落1..N` 全部 `""`
  - `0,2,4`、越界索引、负数非 `-1`、非法字符：行为保持不变（越界丢弃、非法跳过）

- **新增节点：长度 (`YUAN_TXTLength`)**（`Yuan Tool/文本/长度`）
  - 参考 ComfyUI-Easy-Use `len any` 节点，提供 4 种计数口径，输出 `INT`
  - 4 种模式：
    - **字符串**：`len(纯文本)`，字符级
    - **段落**：每一行算一段（含中间空行；末尾换行不算）；空文本 = 0
    - **空行**：strip 首尾空白后按连续空行切分为段块，统计块数；全空白 = 0
    - **列表**：上游真实传入 list 取 `len(列表)`；非 list（纯字符串/数字等）整体视为 1；空文本 = 0
  - 空文本（None / `""`）在 **任意模式下统一输出 0**

- **节点：文本批量替换 (`YUAN_TXTReplace`) 功能优化**
  - 新增 BOOLEAN 参数 **「台词开关」**（显示名「台词保护」）：默认关=正常替换；开=引号内部的「人物说话内容」**完全保留原文，不参与任何查找替换**
  - 支持 6 对引号：`"..."` / `'...'` / `“...”` / `‘...’` / `「...」` / `『...』`
  - 实现机制：栈式配对 + ASCII `"`/`'` 智能判断（优先闭合最近未闭合的同类型）；未闭合开引号/孤闭引号按普通字符处理，不误伤正文
  - 2026-08-05 修复：**半角双引号 `"..."` / 单引号 `'...'` 台词保护失效 BUG**（根因：stack 秩比较下标写错 `[2]` 应为 `[0]`，导致半角引号永远不被正确闭合成对。修复后半角/中文引号保护行为一致。）
